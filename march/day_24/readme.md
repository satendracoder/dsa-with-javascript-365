# Day 24_March – Max Consecutive Ones

Given a binary array nums,
return the maximum number of consecutive 1s in the array.

## Example

Input: nums = [1,1,0,1,1,1]  
Output: 3  

Input: nums = [1,0,1,1,0,1]  
Output: 2  

## Approach

- Traverse the array
- Keep counting consecutive 1s
- If 0 appears → reset count
- Track maximum count

## Complexity

Time Complexity: O(n)  
Space Complexity: O(1)
