# Day 07_Feb – Maximum Subarray

Find the contiguous subarray with the largest sum.

Example:
Input: [-2,1,-3,4,-1,2,1,-5,4]  
Output: 6

Approach:
- Kadane’s Algorithm
- Decide at each index: start new subarray or extend

Time Complexity: O(n)  
Space Complexity: O(1)

LeetCode: Maximum Subarray (Medium)
