# Day 03 Febuary – Longest Strictly Increasing or Decreasing Subarray

Find the length of the longest subarray that is strictly increasing or strictly decreasing.

Example:
Input: [1,4,3,3,2]  
Output: 2

Approach:
- Track increasing and decreasing lengths
- Reset when equal elements appear

Time Complexity: O(n)  
Space Complexity: O(1)
