# Day 06 – Two Sum

Find indices of two numbers such that they add up to a target.

Example:
Input: nums = [2,7,11,15], target = 9  
Output: [0,1]

Approach:
- Use a hash map to store seen numbers
- Check if target - current exists

Time Complexity: O(n)  
Space Complexity: O(n)

LeetCode: Two Sum (Easy)
