# Day 05 – Best Time to Buy & Sell Stock

Find the maximum profit from buying and selling one stock.

Example:
Input: [7,1,5,3,6,4]  
Output: 5

Approach:
- Track minimum price so far
- Update max profit at each step

Time Complexity: O(n)  
Space Complexity: O(1)
