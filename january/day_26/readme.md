# Day 26 – Maximum Difference Between Even and Odd Frequency I

Find the maximum difference between odd and even character frequencies.

Example:
Input: "aaaaabbc"  
Output: 3

Approach:

- Count character frequencies
- Find max odd frequency and min even frequency

Time Complexity: O(n)  
Space Complexity: O(1)
