# Day 14 – Remove Element

Remove all occurrences of a given value in-place and return the new length.

Example:
Input: nums = [3,2,2,3], val = 3  
Output: 2

Approach:

- Use two pointers
- Overwrite unwanted elements

Time Complexity: O(n)  
Space Complexity: O(1)

LeetCode: Remove Element (Easy)
