# Day 20 – Valid Word Abbreviation

Check if an abbreviation correctly represents a given word.

Example:
Input: word = "internationalization", abbr = "i12iz4n"  
Output: true

Approach:

- Use two pointers
- Parse numbers in abbreviation and skip characters in word

Time Complexity: O(n)  
Space Complexity: O(1)
