# Day 13 – Valid Palindrome II

Check if a string can become a palindrome after deleting at most one character.

Example:
Input: "abca"  
Output: true

Approach:

- Use two pointers
- On mismatch, try skipping left or right character

Time Complexity: O(n)  
Space Complexity: O(1)
