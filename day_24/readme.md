# Day 26 – Can Place Flowers

Check if n new flowers can be planted without violating the rule.

Rule:

- No two adjacent flowers can be planted.

Example:
Input: flowerbed = [1,0,0,0,1], n = 1  
Output: true

Approach:

- Traverse array
- Plant flower if left and right are empty

Time Complexity: O(n)  
Space Complexity: O(1)

LeetCode: Can Place Flowers (Easy)
