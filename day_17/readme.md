# Day 18 – Design HashSet

Design a HashSet without using built-in hash libraries.

Methods:

- add(key)
- remove(key)
- contains(key)

Approach:

- Use hashing with buckets
- Store collisions in arrays

Time Complexity:

- Average: O(1)
- Worst: O(n)

Space Complexity: O(n)
